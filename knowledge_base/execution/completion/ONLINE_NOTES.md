## Authority invariants reviewers must enforce

- Receipt lookup is actor-authorized and precedes stale-state rejection. Same action/hash returns its canonical receipt; changed payload conflicts. Reservation generation/instance ownership and current persisted revision guard all asynchronous completion.
- Accept/checkpoint/event/deadline commit is atomic. Simulation occurs outside transactions. Commit result/receipt/replay/outbox before broadcast. An alarm-scheduling failure leaves a discoverable reservation and does not start simulation. Cold ACCEPTED recovery aborts once, never resimulates a nondeterministic action.
- Abort restores bodies/rules while preserving newer pause/connection/terminal state. Terminal forfeit/abandon cancels the reservation; late completion cannot reactivate it. Playback release preserves paused/complete/abandoned status, including placementBlocked next phase. No browser ack advances or persists a result.
- One persisted earliest-deadline alarm handles recovery, playback, grace, promotion and outbox retry. Repeated delivery is idempotent. Last player connection controls the 60-second grace; spectator presence does not prevent it.
- Each encoded replay chunk is at most 32,768 UTF-8 bytes; chunks match shot/count/index, snapshots total at most 1,048,576 bytes, and fixed 451-frame/8,192-fact limits apply. Server clock determines animation offset; client camera/skip does not alter authority. Foreground/event-gap recovery requests the canonical snapshot.
- Sessions/tickets/control epochs determine rights, never username/team/header claims. Rate buckets use hashed account/IP scopes. Names retain display casing and case-insensitive unique lookup. Ticket replay, internal route forwarding, socket revocation and service-outage mutation paths fail closed.
- MatchRoom owns invitation hashes/redemption/roles and rematch consent. Inbox only indexes public metadata; result API acknowledges actual PostgreSQL commit. Unacknowledged outbox keys survive retention. Casual cross-DO allocation is an idempotent saga, not a fabricated cross-DO transaction.
